Operator's Manual (CLI)

DIRECT HARDWARE CONTROL & PYTHON PIPELINE

01. PROBE & LOAD FIRMWARE

Check device state and bring the bootstrap f235 up to operational f135.

# List devices
./build/pakon_probe --list
# Load second-stage firmware
./build/pakon_probe --load-firmware resources/f135.pakfw

02. SCAN HARDWARE

Replay the open handshake and execute a capture-driven scan to pull the raw image binary.

# Verify open handshake
./build/pakon_replay --open
# Run a scan and stream to disk
./build/pakon_replay --scan scan.pakscan --image scan.raw

03. IMAGE PROCESSING

Decode the raw interlaced trilinear strip, split frames, invert C-41, and render.

# Faithful C-41 positive with rendered JPEG
python3 tools/pakon_image.py scan.raw --invert-c41 --jpeg --rotate 90
# Raw negatives only (for third-party inversion)
python3 tools/pakon_image.py scan.raw --rotate 90
